# TodoLite

一个极简的 Windows 桌面待办工具：上面写，下面做——收件箱随手记，列表里专心做。

没有日期、提醒、优先级、标签、搜索、账号、云同步，整个程序里没有一个时间字段。

## 特点

- 单个 exe，零第三方依赖，不写注册表，删掉即卸载干净
- 单实例运行，关窗即退出，没有托盘、没有后台常驻
- 界面与数据里都没有任何时间、日期字段
- 默认只有一栏；需要时点标题右侧的「拆分」再开一栏，右键「合并本栏」即可收回，最多 4 栏
- 长条目自动换行，行高随文字与栏宽自适应，不会被省略成「…」
- 星标标记「正在处理」的任务，可以标多条，自动排到所属栏最前
- 勾选完成后自动沉到列表最下端，并在原地撒一把小礼花；取消勾选回到未完成区末尾
- 界面动效柔和：悬停渐显、对勾生长、星标弹跳、完成礼花、行平滑移动、增删淡入淡出、滚轮缓动、点击涟漪

## 安装

**方式一：直接下载（推荐）**

到 [Releases](../../releases) 下载，双击即可运行。

**方式二：从源码构建**

```bat
git clone <仓库地址>
cd <仓库名>\src
build.bat
```

产物输出到仓库根目录的 `TodoLite.exe`。

> 需要 Windows 10 / Windows 11（系统自带 .NET Framework 4.8），不需要另装任何依赖。

## 使用

1. 在上方收件箱写下要做的事，按 `Enter` 记入列表；要换行按 `Shift+Enter`。
2. 写多行也只会生成**一条** TODO，中间的换行会合并成一个空格。
3. 新条目进入**最近操作的栏**（默认为第一栏），收件箱底部会提示目标栏名。
4. 点勾选框标记完成：原地撒一把小礼花，划线置灰并平滑沉到最下端；再点一次取消，回到未完成区末尾。
5. 点行尾的星形标记「正在处理」，可标多条；星标项自动排在所属栏最前，再点一次取消。
6. 双击文字或按 `F2` 可以改名，`Delete` 或行尾 `×` 删除。
7. 按住某一行上下拖动可在栏内调整顺序；拖到另一栏即可把事项搬过去。
8. 点栏标题右侧的「拆分」新增一栏；右键该栏 →「合并本栏」把内容并入相邻栏后收回该栏。
9. 双击栏标题（或右键 →「重命名本栏」）给每栏起名字。
10. 右键某一栏 →「清除本栏已完成」，一次性清掉该栏做完的。
11. 鼠标点击不会留下深色选中块，只有用 `↑` `↓` 浏览时才有浅色提示。

> 条目文字会根据当前栏宽自动换行，窗口缩放或拆分/合并后行高会重新计算，长内容始终完整可见。

### 快捷键

| 按键                | 作用                    |
| ------------------- | ----------------------- |
| `Enter`             | 记入 TODO               |
| `Shift+Enter`       | 换行                    |
| `F2`                | 编辑选中的事项          |
| `Delete`            | 删除选中的事项          |
| `Space`             | 标记完成 / 取消完成     |
| `S`                 | 加星标 / 取消星标       |
| `Esc`               | 取消编辑                |
| `Ctrl+1`            | 跳到收件箱              |
| `Ctrl+2` / `Ctrl+3` | 跳到第一栏 / 第二栏     |

## 数据

所有数据保存在 exe 同目录的 `todo-data.json`，纯本地、不上传。若该目录不可写（例如放进 `C:\Program Files`），会自动改用 `%APPDATA%\TodoLite\`。

文件为 v3 结构：`draft` 草稿 + `panes` 若干栏（每栏含标题与 `done` / `star` 标记）。旧版单栏数据会在首次启动时自动迁到一栏，不丢内容。

搬走程序时把这个文件一起带上；删掉它就等于清空所有事项。
